# banlat

Banlat is a library for the Lean theorem prover that aims to cover the
theory of [Banach
lattices](https://en.wikipedia.org/wiki/Banach_lattice). This library
is built on top of
[mathlib](https://github.com/leanprover-community/mathlib4). Before
contributing, please see [the companion paper]() to learn more about
our approach and goals.
