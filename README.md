# BanLat

BanLat is a [Lean 4](https://lean-lang.org/) library for vector lattices and Banach
lattices, built on [Mathlib](https://github.com/leanprover-community/mathlib4). Its
goal is to provide a reusable foundation for systematically formalizing contemporary
research in Banach lattice theory and nearby areas of functional analysis.

The [companion paper] gives the full motivation, explains the
development process, presents research-level case studies, and provides a
module-by-module account of version [v0.1.0] of the library.

## Scope

Version [v0.1.0] of BanLat covers:

- the foundations of vector and Banach lattices, including disjointness, Riesz
  decomposition, order completeness, order units, atoms, duals, and quotients;
- sublattices, ideals, bands, projection bands, and positive, order-bounded, regular,
  and order-continuous operators;
- order and uniform convergence, order-continuous norms, and locally solid and locally
  convex-solid topologies;
- AM- and AL-spaces, their duality, and Kakutani representation theorems;
- standard examples such as `C(K)`, `Lᵖ(μ)`, signed measures, and regular Borel
  measures;
- free vector lattices and the free Banach lattice generated by a Banach space; and
- `llarith`, a tactic for proving lattice-linear identities and non-strict inequalities
  by reducing them to the corresponding real statement.

## Approach

BanLat is research-driven rather than an attempt to formalize a monograph from start to
finish. The library grows by adding coherent, reusable prerequisites for concrete
research-level formalizations. The paper describes three such applications, concerning
free Banach lattices, positive projections and Banach lattice algebras, and locally
convex-solid topologies.

Development is human-directed and LLM-assisted. Language models write much of the Lean
implementation, while humans remain responsible for the mathematical roadmap, theorem
statements, API and library design, and close supervision of the signatures. Work is
split into small, nearby goals and checked continuously in Lean. This trades some polish
inside proof scripts for the speed and scale needed to support research, without treating
the library as an opaque autoformalization output.

The project follows three practical principles:

- **Mathlib first.** Existing Mathlib definitions and results are reused wherever
  possible, and BanLat follows its conventions.
- **Incremental and inspectable.** Definitions and theorems are introduced one at a
  time, with design decisions kept under human control.
- **Verified and reusable.** Every theorem is checked by Lean, the project introduces no
  custom axioms, and the public API is organized for downstream work.

## Using BanLat

The Lean toolchain and Mathlib revision are pinned by the repository. To build the
library:

```bash
git clone https://github.com/davidmunozlahoz/banlat.git
cd banlat
lake exe cache get
lake build
```

## Contributing

BanLat is intended to grow into a communal resource for Banach lattice
researchers and Lean users. Contributions are therefore welcome. See
the companion paper for possible directions in which the library could
be extended.
